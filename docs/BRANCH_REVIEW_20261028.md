# 唱片架、检索与键盘操作

## 分支与基线

- 分支：`feat/site-polish-20261028`
- 主干基线：`8d2d431e6dbbcc0ed0119babf5f53a87967f5fd7`
- 基线 tree：`1c2eeb2c2d7e8ed94f8a083ca752b72fab546032`
- 全部 33 个原始文件逐个验证 Git blob SHA，工作从这个精确基线开始。

## 为什么改进

原作品区只能按类别浏览。作品增加后，希望能按歌名、动画、曲目和制作信息快速找到想听的声音，并把常听作品留在自己的唱片架。原自绘详情浮层也缺少原生模态窗口的焦点约束。

## 结果

- 保留海蓝、珊瑚和电音黄色的原有主题。新增海蓝色唱片架工具区，组合关键词、类别、年份、发行顺序或作品名排序；空结果提供恢复全部作品的入口。
- 搜索以 Unicode NFKC 规范化全角字符，并支持多个关键词同时匹配。检索范围包括原资料中的作品名、曲目、关联动画、说明及制作人员。
- 原有 30 部作品可加入本地“我的唱片架”，筛选收藏、查看数量、刷新后保留。存储坏数据会被校验，写入不可用时保留会话状态并提示。收藏移除使卡片消失前，焦点先回到唱片架按钮。
- 其他标签页的收藏变化只更新 UI，不循环回写；保存之前读取最新状态，降低旧页面覆盖新增收藏的风险。
- 详情和影像改为原生 `dialog.showModal()`；焦点留在模态窗口，Esc 关闭顶层窗口，关闭后回到触发控件，保留原来的视觉布局。
- 手机菜单补充展开状态与受控区域，Esc 关闭后恢复菜单按钮焦点。分类按钮公开选中状态；封面换图后可重新加载，避免前一张失败状态沿用。

没有修改资料、媒体地址、播放器数据或现有部署工作流，也没有新增运行依赖。

## 参考

- [Europeana 集合检索](https://www.dataspace-culturalheritage.eu/en/news/introducing-the-new-europeana-collections-website)：参考无需刷新、可组合筛选的集合式发现流程，设计沿用本站主题。
- [MDN 原生 dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)：采用浏览器模态与焦点语义，避免自绘蒙层遗漏键盘行为。
- [MDN storage 事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event)：根据其他标签页的更新同步，不把同步事件当作保存动作。

## 部署与回退

原 `deploy-pages.yml` 仅在 `main` 推送或手动调用时部署。此分支不触发该部署，且没有手动运行工作流。只创建草稿 PR，不合并，也不启用自动合并。

预览时进入作品区：搜索 `Vivy` 应看到 6 项（含说明中提及 Vivy 的 Diva 作品）；收藏一项后打开唱片架、刷新并再打开；切换年份与类别检查组合筛选。打开作品详情，再打开影像，检查 Esc 只关闭顶层且焦点恢复。手机菜单展开后，聚焦其中一条链接再按 Esc。

尚未合并时关闭草稿 PR 即可维持主干原样。要撤回分支改动，在该分支执行 `git revert <本次提交 SHA>`；不要强制推送主干。既有资料与浏览器收藏均不会因代码回退而被清空。
